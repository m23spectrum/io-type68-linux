# IO Type 68 Magnetic для Linux

Драйвер и виджет KDE Plasma 6 для **IO by Red Square Type 68 Magnetic**.

![Виджет IO Type 68 Magnetic](images/kde-widget.png)

## Возможности

- Яркость и выключение подсветки.
- RGB всей клавиатуры или отдельных клавиш.
- Встроенные эффекты, скорость и направление.
- Северное сияние, дыхание, комета и радужная волна — программные эффекты до 30 кадров/с.
- Глубина срабатывания **0,10–3,20 мм** для всех клавиш, WASD или отдельных клавиш.
- Rapid Trigger с раздельными порогами нажатия и отпускания.
- Верхняя и нижняя мёртвые зоны **0–0,50 мм**.
- Управление через виджет KDE или командную строку.

## Совместимость

Linux, Python 3.10+. Для виджета — KDE Plasma 6 и Kirigami.

Поддерживаемое устройство: USB `0c45:0256`, прошивка **1.37**. Поддержка экспериментальная; другие прошивки не проверены.

## Установка

```sh
git clone https://github.com/m23spectrum/io-type68-linux.git
cd io-type68-linux
python3 install.py
```

Запускайте без `sudo`: установщик запросит пароль для установки зависимостей и настройки доступа к USB. На неизменяемых дистрибутивах недостающие зависимости устанавливаются средствами дистрибутива.

После установки добавьте **IO Type 68 Magnetic** через меню KDE «Добавить виджеты». При необходимости переподключите клавиатуру.

## Команды

```sh
io-type68 status
io-type68 lighting --brightness 3
io-type68 lighting --color '#800020'
io-type68 lighting --keys wasd --color '#ff6600'
io-type68 keys --keys wasd --trigger 0.20
io-type68 keys --keys KeyW --rapid on --press 0.10 --release 0.15
io-type68 effect aurora
io-type68 effect none
```

[Полный список команд и параметров](../README.md#cli-examples).

## Удаление

```sh
python3 install.py --uninstall
```

Настройки, сохранённые в клавиатуре, остаются после удаления.

## Ограничения

- Выбор RGB включает постоянную подсветку. Произвольный цвет встроенных анимаций не поддерживается.
- Программные эффекты работают, пока запущена служба; после перезапуска их нужно выбрать заново.
- Макросы, переназначение, SOCD/DKS, калибровка и обновление прошивки не реализованы.
